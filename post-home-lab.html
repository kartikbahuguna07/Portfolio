Setting Up a Home Lab for Web Security Testing

Apr 12, 2026

A few people asked how I test web apps without touching anything I don't have permission to. Here's the rough shape of the lab I run locally.

The setup

A small VM running a couple of deliberately-vulnerable practice applications, isolated on its own virtual network with no route to the internet. An intercepting proxy sits between my browser and the VM so I can inspect and replay requests. Everything interesting — traffic, notes, screenshots — gets logged to a local folder synced to a private git repo.

What I'd tell someone starting out

  • Practice only against apps built for that purpose, run locally
  • Keep notes as you go — the write-up is much easier when you were documenting while you worked, not reconstructing afterward
  • Read other people's write-ups for the "why", not just the "what"
